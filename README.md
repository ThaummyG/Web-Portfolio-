# Watchara Sangwanna — Portfolio

เว็บไซต์พอร์ตโฟลิโอส่วนตัวของ Watchara Sangwanna นักพัฒนาเว็บไซต์จากจังหวัดเชียงใหม่ นำเสนอผลงาน ประสบการณ์ ทักษะ และช่องทางติดต่อ รองรับทั้งภาษาไทยและภาษาอังกฤษ

## คุณสมบัติ

- หน้าเว็บไซต์แบบ single-page พร้อมส่วนผลงาน เกี่ยวกับ ประสบการณ์ และติดต่อ
- สลับภาษาไทยและอังกฤษ โดยเก็บข้อความแยกไว้ใน `locales/th.json` และ `locales/en.json`
- รองรับหน้าจอมือถือ แท็บเล็ต และเดสก์ท็อป
- ใช้ GSAP สำหรับแอนิเมชัน และปิดแอนิเมชันเมื่อผู้ใช้ตั้งค่า reduced motion
- ใช้ HTML, CSS และ JavaScript โดยไม่ต้องติดตั้งแพ็กเกจหรือ build ก่อนใช้งาน

## เปิดดูในเครื่อง

ต้องเปิดเว็บผ่าน local web server เพื่อให้เบราว์เซอร์โหลดไฟล์คำแปลได้ ไม่ควรเปิด `index.html` ด้วย `file://` โดยตรง

หากติดตั้ง Python แล้ว ให้เปิด Terminal ที่โฟลเดอร์โปรเจกต์และรัน:

```powershell
python -m http.server 8000
```

จากนั้นเปิด [http://localhost:8000](http://localhost:8000) ในเบราว์เซอร์ กด `Ctrl+C` ใน Terminal เพื่อหยุดเซิร์ฟเวอร์

หรือใช้ส่วนขยาย Live Server ใน VS Code แล้วเลือก **Open with Live Server** ที่ `index.html`

## โครงสร้างไฟล์

```text
.
├── assets/       # รูปภาพและไอคอน
├── locales/      # ข้อความภาษาไทยและภาษาอังกฤษ
├── index.html    # โครงสร้างหน้าเว็บ
├── main.js       # การแปลภาษาและแอนิเมชัน
└── styles.css    # สไตล์และ responsive layout
```

## การปรับแต่ง

- แก้ไขข้อความภาษาอังกฤษใน `locales/en.json` และภาษาไทยใน `locales/th.json`
- แก้ไขโครงสร้าง เนื้อหาผลงาน และลิงก์โซเชียลใน `index.html`
- ปรับแต่งสี เลย์เอาต์ และ responsive styles ใน `styles.css`
- ปรับพฤติกรรมการสลับภาษาและแอนิเมชันใน `main.js`
- แทนที่รูปภาพใน `assets/` และอัปเดต path ใน `index.html` เมื่อเปลี่ยนชื่อไฟล์

## ไลบรารีภายนอก

หน้าเว็บโหลด Tailwind CSS, GSAP, ScrollTrigger, i18next และ Google Fonts ผ่าน CDN จึงต้องเชื่อมต่ออินเทอร์เน็ตเพื่อใช้งานไลบรารีและฟอนต์เหล่านี้
