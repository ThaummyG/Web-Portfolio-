# Portfolio project context

- Build a personal portfolio website as a single-page landing page using semantic HTML.
- Use Tailwind CSS for utility styling, with project CSS for custom responsive layout and visual details.
- Use GSAP for restrained interface animation and respect `prefers-reduced-motion`.
- Support Thai and English with i18next; keep each language's copy in a separate JSON file.
- Keep the visual direction minimal, clean, uncluttered, orderly, and balanced.
- Make the layout responsive, accessible, and easy to personalize with the owner's real profile, projects, and contact details.
